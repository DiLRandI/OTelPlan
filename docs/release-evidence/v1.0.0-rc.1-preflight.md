## Remaining maintainer actions

Select a reviewed `main` revision after the stacked PRs are accepted. Run full
validation with the candidate version on that revision, then verify the hosted
provenance from the staged assets. Configure the protected release environment
and conduct the RC review and feedback cycle. Use the publication procedure
only after the maintainer approves the reviewed version and tag. See
[release staging and publication](../RELEASING.md#stage-a-candidate-with-provenance).
